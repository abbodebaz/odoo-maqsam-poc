# WATI Settings Tabs

تنظيم صفحة إعدادات WATI إلى تبويبات وظيفية داخل نفس شاشة Odoo:

1. الاتصال و WATI: API + Webhook.
2. الصلاحيات: التحكم المركزي في ظهور خدمات WhatsApp.
3. صندوق الوارد: Mini Inbox والأزرار والقوائم التفاعلية.
4. الأزرار وسجل العميل: Smart WhatsApp Button + Customer WhatsApp Timeline.

لا يغير هذا الترتيب أي قيمة إعدادات أو منطق Backend؛ هو إعادة تنظيم للواجهة فقط.
